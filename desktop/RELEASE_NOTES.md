## 🖥️ MB World Editor para PC (Windows)

**Español**
1. Abajo, en *Assets*, descarga el archivo **MB-World-Editor-Setup** (.exe) y ábrelo. Se instala solo y abre el editor.
2. Si Windows muestra *"Windows protegió tu PC"*: haz clic en **Más información → Ejecutar de todas formas**. (Sale porque el programa todavía no tiene firma digital.)
3. Haz doble clic en cualquier archivo **.mbw** y se abre en el editor.

- Con internet, el editor siempre está en su versión más nueva (no hay que reinstalar nada).
- Sin internet, funciona con la última versión que se usó.
- Tus mundos guardados en el programa son aparte de los del navegador: para pasarlos, expórtalos como .mbw y ábrelos aquí.

**English**
1. Below, under *Assets*, download the **MB-World-Editor-Setup** file (.exe) and open it. It installs by itself and opens the editor.
2. If Windows shows *"Windows protected your PC"*: click **More info → Run anyway**. (It appears because the program is not digitally signed yet.)
3. Double-click any **.mbw** file and it opens in the editor.

- With internet, the editor is always up to date (no need to reinstall).
- Without internet, it works with the last version you used.
- Worlds saved in the program are separate from the browser ones: export them as .mbw and open them here.
